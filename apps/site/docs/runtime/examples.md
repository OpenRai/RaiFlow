# Examples

The repository examples have been rebuilt against the current SDK and runtime.

## Current Situation

Use the examples to see end-to-end integration patterns. For exact method
signatures and model fields, use the SDK README and `@openrai/model` types.

## Existing Example Directories

- `examples/express-api/`
- `examples/next-checkout/`
- `examples/webhook-consumer/`
- `examples/htmx-wallet/`

The examples cover:

| Example | Purpose |
|---|---|
| Express API | minimal server-side integration |
| Next.js Checkout | invoice creation and payment status UI |
| Webhook Consumer | receiving and verifying RaiFlow events |
| HTMX Wallet | wallet-domain flows and account operations |
| RaiFlow CLI | command-line account and payment operations |
